# Hardware Design – Robotic Fish Underwater Monitoring System

## 1. Project Overview

The Robotic Fish is a biomimetic underwater robotics project aimed at developing a fish-inspired robotic platform for future underwater environmental monitoring.

The current development stage focuses on the basic robotic fish model, mechanical structure, movement mechanism, and initial electronic control architecture.

The proposed system uses an ESP32-based control unit with a servo-driven tail mechanism. Additional environmental sensors and camera integration are planned for future development.

## 2. Current Development Stage

**Project Status: Basic Prototype Development**

Current focus areas:
- Basic robotic fish body structure.
- Fish-tail movement mechanism.
- Initial servo motor control.
- ESP32-based control architecture.
- Planning of underwater monitoring electronics.

## 3. Planned Hardware Components

| Component |              | Model |         |  Intended Function |
   
| Microcontroller |      | ESP32 DevKit |       | Main controller |

| Servo Motor |           | MG996R |            |  Tail movement |

| Temperature Sensor |   |  DS18B20 |           | Water temperature |

| Water Quality Sensor |  | TDS Module |       | Dissolved solids estimation |

| Turbidity Sensor |       | SEN0189 |             |   Water clarity |

| Depth Sensor |          | MS5837 |               |  Underwater depth |

| Camera |               | ESP32-CAM OV2640 |      |  Underwater visual monitoring |

*The components listed above represent the planned hardware configuration, not necessarily completed integration.*

## 4. Development Roadmap

### Phase 1 – Basic Model Development
- Robotic fish body design.
- Mechanical tail arrangement.
- Initial servo movement.
- ESP32 control development.

### Phase 2 – Sensor Integration
- Temperature monitoring.
- TDS measurement.
- Turbidity measurement.
- Pressure and depth monitoring.

### Phase 3 – Visual Monitoring
- ESP32-CAM integration.
- Underwater image capture.
- Camera enclosure development.

### Phase 4 – System Integration and Testing
- Complete electronic integration.
- Waterproof enclosure.
- Underwater movement testing.
- Sensor calibration and data logging.

## 5. Future Applications

- Underwater environmental observation.
- Water quality monitoring.

- Underwater inspection.

## 6. Project Objective

To develop a compact biomimetic robotic fish platform that combines fish-like movement with environmental sensing and underwater visual monitoring capabilities.
